Protection OMPI (Organisation Mondiale de la Propriété Intellectuelle) issu de l'ONU

sui generis partait d'une base de droit d'auteur

Dispositions types proposées mais pas utilisées

Logiciels sont été protégés par un droit existant : droit d'auteur.
Mais pas totalement exclus des droits des brevets

La protection des logiciels par le droit d'auteur est un droit spécial.

Protection a différentes sources juridiques :
- Droit d'auteurs : 3 juilllet 1985 et du 10 mai 1994 (CPI à la suite de la directive europeenne)
- Directive européenne 91/50 du 14 mai 1991 -> remplacée par la directive 2009/24/CE du 23 avril 2009
- Brevet : 2 janvier 1968 (France)-> changée en 13 juillet 1978 
- 5 octobre 1973 (UE Convention sur le brevet européen)

La France n'a pas attendu la protection de l'UE.
Deux droits différents, national et européen.

Logiciels sont protégés par le droit d'auteur et exclus en principe des brevets mais il y a des exceptions.

##  Par le droit d'auteur

Création d'une mise en forme d'une idée originale.
C'est marqué dans la loi L112-2 CPI. Le logiciel est une oeuvre de l'esprit.
"Sont des oeuvres de l'esprit protégées les logiciels ainsi

Création propre à l'auteur lorsque l'auteur a pu faire des choix libres et créatifs. (Européen)

### Le logiciel tel que saisie par le droit d'auteur
Au niveau juridique pas de définition précise du logiciel -> évite une définition trop précise pour ne pas exclure des logiciels.

Définition : Séquence d'instructions interprétable par une machine.

Logiciel système : système d'exploitation
Logiciel application : logiciel de traitement de texte par exemple

Les différentes étapes de conception : 
- Phase d'analyse : analyse fonctionnelle (étude des besoins) et analyse organique (Planification de l'architecture de la solution)
- Phase de programmation : Rédaction des instructions en code source

Les parties du logiciel :

 - Analyse  : travail préparatoire et matériel de conception préparatoire

 - Planification de l'architecture de la solution -> résulte en la création d'une structure de programme

 - Instructions : Constituant le code source et code objet

 - Interface Logique : les API (Application Programming Interface) qui permettent de communiquer avec le système d'exploitation par exemple

 -Effets audiovisuels : fichiers médias
 
 - Interfaces graphiques : interface utilisateur interprétée par la machine (Exemple le web design)

 - Langage de programmation : langage de programmation utilisé pour écrire le code source

Les 4 premiers droit spécial du logiciel (droit d'auteur), les formes programmés et le travail préparatoire.

Le reste est protégé par le droit d'auteur de droit commun.

On fait cette distinction non pas pour des raisons de condition de protection, ni pour des raisons de date de protection 

### Différence entre le droit d'auteur spécial logiciel et le droit d'auteur de droit commun
Spécial logiciel s'inscrit dans le droit d'auteur de manière spéciale.

Droit d'auteur spécial logiciel c'est meilleur pour les créateurs, les investisseurs(exploitants) et les utilisateurs logiciels.

Première adaptation c'est l'article L121-7 de la CPI, l'auteur :
- Peut pas s'opposer à la modification du logiciel par son cessionnaire lorsqu'elle n'est préjudiciable ni à son honneur ni à sa réputation. Ne peut pas non plus exercer son droit de repentir ou de retrait (Droit d'arrêter un contrat pour des raisons artistiques). C'est lié au droit au respect de l'intégrité de l'oeuvre et aux droits moraux.

Droit moral fortement réduit. Pour les droits patrimoniaux (droit de reproduction, droit de mise sur le marché et droit de modification L122-6 CPI) 

Droit de reproduction étendue : reproduction permanente ou provisoire n'est pas possible sans autorisation de l'auteur. (Article L122-6 CPI)

Pas d'exception de copie privée pour les logiciels.
Pas de droit de mise sur le marché pour les logiciels.

Epuisement des droits : dès lors qu'un logiciel a été légalement mis sur le marché, cet exemplaire peut être revendu sans l'autorisation de l'auteur. 
Concerne aussi les logiciels, en téléchargeant un logiciel, on acquiert une licence d'utilisation. Cette licence peut être revendue. (CJUE 3 juillet 2012 UsedSoft)

Il y a des actes possibles uniquement avec l'autorisation de l'auteur mais il y a certaines exceptions. Exemple : Une copie doit être faite avec l'accord de l'auteur sauf pour l'usage privé.
>> Cette exception de copie privée n'existe pas pour le logiciel.

Des exceptions pour les logiciels :
- Avec une licence d'utilisation, vous pouvez reproduire le logiciel et le modifier si c'est nécessaire pour son utilisation. Par exemple : corriger une incomptabilité ou un bug avec un autre logiciel.
- Utilisateur légitime peut tester,étudier le fonctionnement du logiciel pour déterminer les idées et principes qui sont à la base de n'importe quel élément du logiciel. (Article L122-6-1 CPI)
- Utilisateur légitime a le droit de décompiler le logiciel pour avoir les informations nécessaires pour l'interopérabilité. Il faut aussi que ces informations ne soient pas déjà facilement et rapidement disponibles par le titulaire du droit. On ne peut aussi que décompiler LA partie nécessaire pour l'interopérabilité. Cette décompilation ne peut pas être partagé à des tiers et ni porter atteinte aux droits du titulaire du droit.   
Exemple : Pour faire fonctionner un logiciel avec un autre logiciel on doit vérifier quel module java est utilisé pour étudier la compatabilité et cette information n'est pas écrite dans la documentation. Donc on peut décompiler uniquement le fichier.class qui implémente l'interface logique (API) pour voir comment il fonctionne.
- Titularité du logiciel est aussi différente quand le logiciel est créé par un salarié. Le salarié est propriétaire en droit commun, mais en droit spécial logiciel, c'est l'employeur qui est propriétaire. (Article L113-9 CPI) "Les droits patrimoniaux sur les logiciels créés par un ou plusieurs salariés dans l'exercice de leurs fonctions ou d'après les instructions de leur employeur, sont dévolus à l'employeur qui est seul habilité à les exercer."  
Donc deux conditions : Créé par un salarié soit dans l'exercice de ses fonctions ou soit d'après les instructions de l'employeur. Si ces conditions ne sont pas remplies, le salarié est propriétaire du logiciel.  
Sauf stipulation contraire, dans le cas où le stagiaire crée un logiciel, c'est l'entreprise d'accueil qui est propriétaire du logiciel.   
Exemple : Stagiaire chez Google crée un logiciel, c'est Google qui est propriétaire du logiciel. Sauf si dans la convention de stage, il est stipulé que le stagiaire est propriétaire du logiciel.
